## 1. Global system

### 1.1 Fluid rem (most important rule)
```css
html { font-size: 1rem; }                                                   /* ≤ 767 → 16px */
@media screen and (min-width: 768px) and (max-width: 991px) { html { font-size: 1vw; } }
@media screen and (min-width: 992px) and (max-width: 1919px) { html { font-size: 1vw; } }
@media screen and (min-width: 1920px) { html { font-size: .8vw; } }
```
1 rem = **14.4 px @1440**, **9.91 px @991**, **16 px @390**. Every size in the Webflow CSS is in rem/vw, so desktop and
tablet are the same layout scaled; only the ≤ 767 / ≤ 479 rules change the layout. Keep all sizes in rem.
